## Seedance Cloak v2.1.1

영상·이미지 속 **얼굴만** 골라 검출/매칭을 회피하거나, 얼굴에 맞춘 **격자(그리드)** 를 씌우는 데스크톱 툴입니다.

### 설치 (동료용 · 클릭 한 번)
1. 아래 **Assets** 에서 **`SeedanceCloak-Setup.exe`** 다운로드
2. 더블클릭 → 자동 설치 + 실행 (관리자 권한/추가 설정 불필요)
3. 이미 설치돼 있다면 앱을 켜면 **자동 업데이트** 안내가 뜹니다

> 포터블: `SeedanceCloak_v2.1.1.zip` · SmartScreen 경고 시 [추가 정보 → 실행] · Windows 10/11

### v2.1.1 변경점 (UI/UX 개선)
- **미리보기 프레임 이동**: ◀▶·슬라이더로 프레임을 이동하며 **그 프레임에 그리드/엔진이 실제 적용된 결과**를 확인. 첨부 시 얼굴이 잡히는 프레임을 자동 탐색
- **미리보기 폭 확대 + 좌우 분리바(드래그)** 로 컨트롤/미리보기 폭 자유 조절
- 여러 파일 **썸네일 카드**에 **× 삭제 버튼** 추가(글리프 대신 아이콘 직접 렌더 → 항상 표시)
- 슬라이더 **마우스 휠 오조작 방지** + 값마다 **기본값(↻) 버튼**
- **회피 엔진 기본값 모두 OFF** + 접이식 카드로 정리
- 실행 버튼/아이콘 표시 개선

### 기능
- 회피 엔진 A/B/C + 얼굴 그리드(격자 수·두께·색·투명도·모양·정렬·점)
- 이미지 단일/복수(배치), 동영상 4초 채우기, 얼굴 트래킹, 원본 화질 보존
- FFmpeg 9.0 번들, YuNet 얼굴 검출 내장, 자동 업데이트
