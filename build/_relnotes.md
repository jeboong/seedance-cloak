## Seedance Cloak v2.1.3

영상·이미지 속 **얼굴만** 골라 검출/매칭을 회피하거나, 얼굴에 맞춘 **격자(그리드)** 를 씌우는 데스크톱 툴입니다.

### 설치 (동료용 · 클릭 한 번)
1. 아래 **Assets** 에서 **`SeedanceCloak-Setup.exe`** 다운로드 → 더블클릭(자동 설치+실행)
2. 이미 설치돼 있으면 앱을 켜면 **자동 업데이트** 안내가 뜹니다

> 포터블: `SeedanceCloak_v2.1.3.zip` · SmartScreen 경고 시 [추가 정보 → 실행] · Windows 10/11

### v2.1.3 버그 수정
- **슬로우모션/오디오 길이 불일치 렌더 실패 수정**: 토파즈 아폴로 등으로 **영상만 늘린(오디오는 원본 길이) 클립**을 넣으면 `FFmpeg 파이프 오류`로 렌더가 조기 종료되던 문제를 고쳤습니다. 원인은 `-shortest` 가 짧은 오디오에 맞춰 영상을 잘라버린 것으로, 이제 **오디오를 무음 패딩해 영상 전체 길이에 맞춰** 정상 인코딩합니다.
- ffmpeg 가 정상 종료(반환코드 0)한 경우 파이프가 끊겨도 성공으로 처리, 오류 메시지에서 진행 통계줄을 걸러 **진짜 원인만 표시**하도록 개선.

### 최근 기능(이전 버전 포함)
- 회피 엔진 A/B/C + 얼굴 그리드(자동/수동 배치, 격자 수·두께·색·투명도·모양)
- 이미지 단일/복수(배치), 4초 채우기(단독 렌더 가능), 얼굴 트래킹, 원본 화질 보존
- 렌더 전 프레임 이동 미리보기, 저장 경로 기억, FFmpeg 9.0 번들, 자동 업데이트
