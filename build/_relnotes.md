## Seedance Cloak v2.1.2

영상·이미지 속 **얼굴만** 골라 검출/매칭을 회피하거나, 얼굴에 맞춘 **격자(그리드)** 를 씌우는 데스크톱 툴입니다.

### 설치 (동료용 · 클릭 한 번)
1. 아래 **Assets** 에서 **`SeedanceCloak-Setup.exe`** 다운로드
2. 더블클릭 → 자동 설치 + 실행 (관리자 권한/추가 설정 불필요)
3. 이미 설치돼 있다면 앱을 켜면 **자동 업데이트** 안내가 뜹니다

> 포터블: `SeedanceCloak_v2.1.2.zip` · SmartScreen 경고 시 [추가 정보 → 실행] · Windows 10/11

### v2.1.2 변경점
- **4초 채우기만 켜도 렌더 가능**: 회피 엔진·그리드가 모두 꺼져 있어도 4초 채우기가 켜져 있으면 처리됩니다.
- **수동 그리드 배치(트래킹 OFF)**: 얼굴 트래킹을 끄면 그리드가 **항상 화면에 표시**되고, **미리보기에서 드래그**하거나 **위치 X·Y / 너비 · 높이 값**으로 원하는 곳에 고정할 수 있습니다.
- **저장 경로 기억**: 한 번 지정한 저장 폴더가 이후 첨부에도 계속 유지됩니다(프로그램을 다시 켜도 유지).

### 기능
- 회피 엔진 A/B/C + 얼굴 그리드(격자 수·두께·색·투명도·모양·정렬·점, 수동/자동 배치)
- 이미지 단일/복수(배치), 동영상 4초 채우기, 얼굴 트래킹, 원본 화질 보존
- 렌더 전 프레임 이동 미리보기, FFmpeg 9.0 번들, 자동 업데이트
